# 마음동화책방 — 최신 정의서와 선택형 시안의 차이

기준일: 2026-10-16. 비교 기준: 최신 상세 요구사항 정의서 1.1(공개 기준 `504e343`)과 현재 저장소. 이 문서는 구현 전에 작성한 범위 기준이다.

후속 확정: 사용자가 『화분을 놓을 자리』의 제외를 요청하여 로컬 어른 책장은 두 권으로 변경했다. 아래 ‘세 권 보존’은 이 후속 결정 이전의 기준 비교이며, 원문 자료는 보관하되 활성 목록에서 해당 책을 뺐다. 공개 사이트는 아직 세 권인 기존 상태다.

최신 후속 작업: 별도 표지·둥근 틀·다양한 인물 개편과 가족/직장동료 두 권 추가로 로컬 검토 책장은 네 권이 되었다. 최신 검토 범위는 [어른 책장 개편 기록](adult118-review.md)을 따른다. 공개는 사용자 확인 뒤 진행한다.

## 새 시안의 경계

- 검토 주소: `/pilot/`. 원작 『작은 손에 담긴 따뜻한 빵』의 상황을 바탕으로 쓴 **새로운 가상 선택 장면**이다. 원문을 대체하지 않는다.
- 기존 삽화는 바꾸지 않는다. 이번 시안은 글·단서·반응·결말 구조를 먼저 검토하는 화면이다. 원작 그림이나 녹음이 새 선택 장면과 일치한다고 오해하지 않도록 자동 연결하지 않는다.
- 취소한 인생게임·그림일기·점수·강제 기록 제출·공개 벽을 다시 만들지 않는다.
- 한국어·영어·스페인어 시안 자료를 제공하되 새 외국어 문장은 외부 원어민 감수 전 초안이다. 누락된 번역은 원문으로 몰래 대체하지 않는다.
- 저장소의 기존 원문 파일과 정의서 1.1은 변경하지 않는다. 이번 확장은 이 비교 문서와 README로 설명한다.
