# 어른 책장 개편 — 승인된 반영 내용

기준일: 2026-10-16. 사용자가 화면 검토 후 **어른 동화와 앞서 승인한 내용의 GitHub 반영**을 요청했다. 이 요청이 앞선 공개 보류 지시를 대체한다.

## 책장과 표지

- 『화분을 놓을 자리』는 활성 목록에서 제외한 상태를 유지한다. 원고·번역·그림은 보관한다.
- 남은 두 권의 책 소개에 보이던 6칸짜리 장면 모음 대신 **새로 그린 한 장짜리 표지**를 사용한다.
- 책장의 작은 표지와 책을 클릭한 큰 소개 그림은 같은 파일을 사용한다.
- 아이 책장의 둥근 그림 틀, 정사각형 그림 비율, 제목·장소·책 펼치기 배치와 같은 구조로 통일한다.
- 따뜻한 크림색 종이, 부드러운 손그림 질감과 햇빛을 공통으로 삼고, 피부색·표정·머리·옷은 인물별로 구분한다.
- 본문은 각 작품 6장면, 기본 관점과 상대 관점의 그림을 따로 그렸다. 표지는 장면 모음 파일을 사용하지 않는다.

## 원문 보존과 편집 범위

- 기존 원고·기존 번역 파일은 보관한다. `adult-character-refresh.js`가 화면용 인물·표지·새 장면 그림·표현을 적용한다.
- 기차역의 후반부는 새 그림의 지도 함께 보기, 표를 챙기는 사람과 맞도록 물건·손동작 문장을 조정했다. 도움을 함께 나눈다는 이야기의 뜻은 유지한다.
- 새 두 권의 세 언어 원고는 `new-adult-stories.js`에 둔다. 새 책 ID는 `flowers`, `notes`다.
- 영어·스페인어의 인칭·대명사는 새 인물에 맞추었다. 외부 원어민 문학 감수를 마쳤다는 뜻은 아니다.
- 기존 아이 동화의 원문과 그림은 바꾸지 않는다. 공통 독서 화면의 스페인어 나이 표시에서 한국어 ‘살’이 남지 않도록 표시 함수만 수정했다.
- 새 작품도 읽기·다른 마음으로 읽기·페이지 버튼·처음부터·스와이프·마음열쇠·언어 전환을 공통 독서 화면에서 제공한다. 직접 녹음은 미준비 상태이며 합성 음성을 넣지 않는다.

## 검토 결과

### 후속 원고·화면 검토(119)

- 읽기 쉬우며 기존 등장인물과 중복되지 않는 이름으로 직장동료의 이름을 **다비(Davi)**로 변경했다. 나이·브라질 배경·그림은 유지한다.
- 발표 내용을 동네 산책길 안내 책자 기획안으로 구체화했다. 첫 장의 예시, 설명 순서 조정, 예시를 그대로 쓰려는 이유를 두 관점에서 구체적인 대화와 행동으로 풀어 썼다.
- “같은 파일” 대신 다비가 서류철을 펼쳐 들고 렌이 첫 장부터 종이를 순서대로 넣는 행동으로 끝맺었다. 영어·스페인어도 동기화했다.
- 어른 책장 아래의 긴 소개 문장은 모두 장소 이름으로 바꾸고 작은 화면에서도 18px로 읽을 수 있도록 했다. 책 소개 화면의 설명은 유지한다.
- 어른 동화의 보이는 마음열쇠 버튼은 그림 아래쪽으로 옮겼다. 원래 표정·손동작의 위치는 확대용 좌표로 유지하고 연결선으로 이어준다. 아이 동화의 배치 규칙은 변경하지 않았다.
- 버튼의 경계·겹침·얼굴 영역 회피를 48장면 × 세 화면 너비로 자동 검사했고, 사용자 화면 563×668에서도 48장면을 실제로 열어 확인했다. 버튼을 눌러 원래 표정 확대가 나오는 것도 확인했다.
- 수정한 동료 이야기 36개 언어·관점·장면 화면과 세 언어의 네 권 책장 장소 표기를 확인했다. 이후 사용자의 명시적 요청에 따라 GitHub 반영 대상으로 확정했다.

- 자료 검사: 네 권 × 두 관점 × 여섯 장면 × 세 언어의 본문·제목·인물·마음열쇠·그림 파일 연결 확인. 새 연령·관계 설정과 둥근 표지 틀, 스페인어 나이 표시 검사 포함.
- 실제 브라우저: 한국어 48장면, 영어·스페인어 96장면, 총 144장면의 본문과 그림 연결·마음열쇠 두 개·가로 넘침 없음 확인.
- 휴대전화 폭 390px: 세 언어의 책장·네 권의 소개·상대 관점 독서 화면 27개 확인. 표지 파일과 버튼 두 종류가 연결되고 가로로 넘치지 않음. 검사 뒤 화면 크기 원복.
- 새 모녀 책 엘레나 관점 4/6에서 실제 언어 메뉴로 한국어→영어→스페인어를 선택한 뒤에도 책·관점·장면이 유지되는 것을 확인했다.
- 한 장짜리 표지 네 개와 본문 장면 모음 여덟 개를 새로 그렸다. 본문 그림의 실제 칸 경계를 측정해 장면의 머리나 손이 다음 칸과 섞이지 않도록 표시 영역을 맞췄다.
- 그림·문학적 표현과 외국어의 최종 취향 판단은 사용자의 검토 단계다. 자동 검사가 외부 원어민 감수나 모든 해석의 적절성을 보증하지 않는다.
