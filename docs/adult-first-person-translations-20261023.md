# 어른 동화 영어·스페인어 1인칭 수정 검수

검수일: 2026-10-23

사용자가 확인한 한국어 1인칭 수정본을 기준으로, 영어와 스페인어의 네 권·두 관점·여섯 장을 모두 다시 썼습니다. 영어 48개, 스페인어 48개로 총 96개 본문입니다. 현재 로컬 검토본에 반영했으며 이번 1인칭 수정은 공개 사이트 배포 전입니다.

## 화자 원칙

- 동화 읽기에서는 주인공인 내가 내 경험을 말합니다. 다른 마음으로 읽기에서는 다른 인물인 내가 같은 순간을 말합니다.
- 내 생각과 감정은 내가 이야기합니다. 상대의 마음은 관찰·추측·대화를 거쳐 알아가며, 아직 알지 못한 속마음을 사실처럼 설명하지 않습니다.
- 영어는 대화 밖의 서술도 I, me, my, we 등으로 화자를 이어갑니다.
- 스페인어는 yo를 매번 반복하지 않고, 1인칭 동사와 me, mi 등의 표현을 자연스럽게 사용합니다. 등장인물에 맞는 성·수와 상대에 따른 호칭도 살폈습니다.
- 앞서 명확히 한 사건 순서와 공통 대사는 유지했습니다.
