# 공개 전 변경사항과 검토 기록

기준일: 2026-10-16. **GitHub 커밋·푸시·배포 없음.** 기존 공개 사이트는 변경하지 않았다.

**후속 공개 승인:** 사용자가 이 기록 이후 GitHub 반영을 요청했다. 아래 보류 표시는 승인 전 검토 이력이다. 이번 배포 대상은 책 제외, 선택형 시안, 문서이며 시안은 기존 메뉴에 연결하지 않는다. 공개 후에는 `/pilot/` 직접 주소로 볼 수 있다. 캐시에 이전 책 목록이 남지 않도록 여섯 HTML의 관련 스크립트 주소 버전을 갱신하고 승인 변경 목록에 기록했다.

## 후속 요청: 화분을 놓을 자리 제외

사용자가 연애소설처럼 느껴져 다른 이야기로 교체하겠다고 요청했다. 이에 로컬 세 언어 어른 책장·활성 독서 목록에서 『화분을 놓을 자리』를 제외했다. 기존 독서 주소는 해당 언어의 어른 책장으로 돌아간다. 원문·번역·그림은 삭제하지 않고 보관한다. 새 작품은 아직 정하지 않았다.

아래의 ‘기존 324개 파일 보존’은 선택형 시안 최초 완료 시점의 기록이다. 이후 사용자 승인에 따라 `adult-preview-data.js`의 활성 목록 제외와 `adult-reader-data.js`의 이전 주소 복귀 처리가 추가되었다. 원래 기준 해시는 유지하고 두 파일의 허용 변경을 `pilot/approved-changes.json`에 이유와 함께 기록했다. 나머지 기존 파일은 동일하다. 한국어·영어·스페인어 책장에 두 작품만 남는 것과 이전 주소 복귀를 실제 브라우저에서 확인했다. GitHub 반영은 보류한다.

## 이번에 달라진 부분

- 기존 추적 파일 중 README만 변경했다. 이전의 어른 책 준비 중 안내를 현재 공개 상태로 고치고 실행·편집·검사·공개 및 비공개 운영 절차를 추가했다.
- 새 docs/에는 정의서 1.1의 변경 없는 사본, 차이 분석, 이 검토 기록이 있다.
- 새 pilot/에는 세 역할의 선택 이야기 자료, 경로 엔진, 검토 화면, 로컬 서버, 자동 검사, 원문 보존 기준 목록이 있다.
- 대문·책장·기존 동화 원문·그림·녹음은 보존했다. 새 시안을 기존 메뉴에 연결하지 않았다.
- 시안은 원작 상황을 바탕으로 새로 쓴 가상 선택 글이다. 새 장면의 그림·낭독은 제작 범위에 포함하지 않았다.

## 역할별 경로와 결말

a/b는 번역과 관계없이 유지되는 선택 ID다. 순서대로 두 번 고른다. 선택 직후 반응은 화면 아래에 누적된다. 첫 번째 선택마다 두 번째 상황이 달라지고, 두 번째 선택으로 서로 다른 결말에 도달한다.

| 역할 | 경로 | 선택한 말·행동 | 결말 |
|---|---|---|---|
| 지우 | a → a | “무슨 걱정 있어?” 하고 물어요. → “같이 책 사이에 넣어 볼까?” 하고 제안해요. | 무엇이 걱정인지 묻고 함께 책갈피를 넣었어요. 준호의 시계 보기에는 내가 몰랐던 사정이 있었어요. |
| 지우 | a → b | “무슨 걱정 있어?” 하고 물어요. → 준호가 스스로 정리할 동안 빵을 물어봐요. | 준호의 걱정을 듣고 스스로 정리할 시간을 주었어요. 나는 할아버지께 드릴 빵을 물었어요. 각자 필요한 일을 할 수 있었어요. |
| 지우 | b → a | 조금 더 살펴보며 내 쪽지를 펴요. → “같이 책 사이에 넣어 볼까?” 하고 제안해요. | 조금 지켜본 뒤 도움을 제안했어요. 준호가 고개를 끄덕인 뒤에야 책에 손을 댔어요. 기다린 뒤에도 말을 건넬 수 있었어요. |
| 지우 | b → b | 조금 더 살펴보며 내 쪽지를 펴요. → 준호가 스스로 정리할 동안 빵을 물어봐요. | 책갈피를 정리하는 준호 곁에서 나는 빵을 골랐어요. 무슨 마음인지 모두 알지는 못해도, 화가 났다고 서둘러 정하지 않기로 했어요. |
| 준호 | a → a | “너 때문이 아니라 책갈피가 걱정돼.” → 지우에게 쪽지를 함께 봐도 되는지 물어요. | 내 걱정을 설명하고 지우의 쪽지도 함께 보았어요. 같은 줄에 서 있어도 우리가 생각하던 것은 달랐어요. |
| 준호 | a → b | “너 때문이 아니라 책갈피가 걱정돼.” → 지우가 고를 수 있도록 옆에서 기다려요. | 내 걱정을 말한 뒤 지우가 고를 시간을 주었어요. 옆에 조용히 있어 주는 것도 내가 할 수 있는 일이었어요. |
| 준호 | b → a | 먼저 책갈피를 안전하게 넣어요. → 지우에게 쪽지를 함께 봐도 되는지 물어요. | 책갈피부터 넣고 지우에게 말을 걸었어요. 뒤늦게라도 쪽지를 함께 보며 서로의 사정을 조금 알게 되었어요. |
| 준호 | b → b | 먼저 책갈피를 안전하게 넣어요. → 지우가 고를 수 있도록 옆에서 기다려요. | 책갈피를 챙긴 뒤 지우 옆에서 기다렸어요. 내 걱정은 정리됐지만 지우가 어떻게 느꼈는지는 아직 몰라요. 다음에 이야기할 여지가 남았어요. |
| 빵집 주인 | a → a | “재촉한 게 아니라 부드러운 빵을 알려 준 거야.” → “누구와 먹을 빵이니?” 하고 물어요. | 손짓의 뜻을 설명한 뒤 누구를 위한 빵인지 물었어요. 같은 빵도 먹을 사람의 사정에 따라 다르게 골라야 했어요. |
| 빵집 주인 | a → b | “재촉한 게 아니라 부드러운 빵을 알려 준 거야.” → 두 빵의 부드러움을 차분히 설명해요. | 재촉한 것이 아니라고 말하고 두 빵을 설명했어요. 지우가 직접 고른 빵을 확인하고 봉투에 넣었어요. |
| 빵집 주인 | b → a | 손을 내리고 고를 시간을 주어요. → “누구와 먹을 빵이니?” 하고 물어요. | 기다려 준 뒤 조심스럽게 물었어요. 지우의 쪽지 뒤에는 할아버지를 생각하는 마음이 있었어요. |
| 빵집 주인 | b → b | 손을 내리고 고를 시간을 주어요. → 두 빵의 부드러움을 차분히 설명해요. | 기다렸다가 빵의 차이를 설명했어요. 지우가 고른 빵을 담으며, 다음에는 내 손짓의 뜻도 말로 덧붙여 보고 싶었어요. |

## 검사 결과

- 자동 검사 18개 통과: 12경로 도달, 두 번의 두 갈래, 모든 장면 도달, 단서·반응 연결, 세 언어 자료, 언어/주소 상태 복원, 잘못된 주소, 누락 번역, 막힌 연결·순환 거부, 기존 파일 보존.
- 기존 추적 파일 324개의 SHA-256이 작업 전 기준과 일치(README 제외). 인덱스·원문·자산을 덮어쓰지 않았다.
- 실제 브라우저에서 12경로 × 3언어 = 36개 결말 화면을 선택 버튼으로 확인했다. 각 경로의 반응 기록 2개, 누락 안내 없음, 현재 검토 창의 가로 넘침 없음.
- 빵집 주인 bb 결말에서 언어 ko→en→es→ko 전환 및 새로고침 후 역할·장면·선택 두 개 유지 확인. 한 선택 되돌리기 후 follow-b와 기록 한 개 확인.
- 임시로 스페인어 시작 본문 하나를 누락시켜 실제 화면의 Próximamente 표시 확인. 한국어 본문으로 대체되지 않았다. 임시 누락을 제거한 뒤 세 언어 전체 경로를 다시 확인했다.
- 그림·낭독은 시안에 새로 연결하지 않았으며, 외국어 문학적 자연스러움은 외부 원어민 감수 전이다. 자동 검사와 브라우저 확인이 이를 대신하지 않는다.
