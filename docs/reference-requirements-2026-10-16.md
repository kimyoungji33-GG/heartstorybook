## 1. 프로젝트 개요

### 1.1 서비스명과 한 문장 소개

**마음동화책방**은 일상 속 같은 사건을 서로 다른 인물의 자리에서 다시 읽으며, 나의 짐작과 다른 사람의 마음이 다를 수 있음을 경험하는 그림동화 웹사이트다.

### 1.2 핵심 목적

1. 그림과 이야기를 통해 자신의 마음을 조용히 떠올리고 알아차린다.
2. 표정·행동·말을 살펴보되, 보이는 모습만으로 상대의 마음을 성급히 단정하지 않는다.
3. 다른 인물의 이야기를 읽으며 처음의 해석을 돌아본다.
4. 서로 다름을 이해하고 인정하며, 일상에서 배려할 여지를 발견한다.
5. 이야기를 읽은 뒤 억지로 결론이나 답을 적지 않고 잠시 머무를 수 있다.

### 1.3 서비스가 지향하는 경험

- 정답을 맞히는 감정 시험이나 지식 학습보다, 이야기 속 사람을 만나고 관점을 바꾸는 경험을 제공한다.
- 잘못한 사람을 찾아내거나 한 인물만 옳다고 판정하지 않는다.
- 감정을 추상적인 설명으로 가르치기보다, 구체적인 사건·물건·표정·손동작·대화에 담는다.
- 어린이와 어른의 감정에 우열을 두지 않는다. 어른의 하루에도 사소하지만 섬세한 마음이 있음을 다룬다.
- 홈페이지에 명상·수련 방법이나 치료 효과를 전면에 내세우지 않는다.

### 1.4 이용 대상

- 그림동화를 읽는 어린이
- 함께 읽는 보호자·교사·진행자
- 일상 속 마음과 관계를 돌아보고 싶은 성인

‘아이의 마음’과 ‘어른의 마음’은 주인공과 이야기의 초점을 구분하는 책장 이름이다. 이용자의 나이에 따른 접근 제한이 아니다. 누구나 두 책장을 읽을 수 있다.

## 2. 현재 공개 상태와 다음 배포 범위

| 구분 | 기준일 현재 확인 상태 | 최신 확정 요구 |
|---|---|---|
| 아이의 마음이 담긴 동화 | 여섯 작품 공개. 각 작품 여섯 장면, 기본 화자와 다른 두 인물 | 세 언어 공통 읽기·본문·경로·레이아웃 재검수 완료 |
| 어른의 마음이 담긴 동화 | 세 작품을 공개 책장에 연결 완료 | 아이 동화와 같은 읽기 기능, 두 관점, 세 언어 제공 |
| 어른 동화 한국어 원고 | 사용자 문장 수정 및 마지막 그림 대조 수정 반영 완료 | 최신 수정 문장을 최종 원고로 유지 |
| 어른 동화 영어·스페인어 | 제목·소개·본문·관점·마음열쇠 연결 및 화면 검수 완료 | 원어민 외부 감수 완료나 해당 언어 낭독 제공을 뜻하지 않음 |
| 어른 동화 그림 | 기본·다른 관점 총 36장면 재작화 및 연결 완료 | 서연·하준 삽화의 결, 장면별 섬세한 표정과 관점별 구도 유지 |
| 마음열쇠 | 공개 동화의 배경을 반투명으로 변경한 상태 | 모든 활성 동화에 같은 표시 방식 적용 |
| 만약 이랬다면 어땠을까? | 청개구리 이야기 및 마음 건네보기 활동 공개 | 기존 흐름 유지 및 세 언어 재검수 |
| 마음의 소리 | 소리를 듣고 떠오르는 느낌·풍경을 살펴보는 활동 공개 | 감정 정답 맞히기로 오해되지 않도록 유지 |
| 마음 열쇠 알아보기 | 서연·하준 빵집 그림과 표정·행동·말 설명 공개 | 설명·예시·이동 동선 유지 |
| 마음으로 만나는 세상 | 제목과 준비 중 화면만 유지 | 기존 동물·식물·우주 내용을 임의로 복원하지 않음 |
| 대문 애니메이션 | 적용하지 않기로 결정 | 승인된 정지 삽화 유지 |
| 내 마음 꾸러미·그림일기·인생게임 | 제외·삭제 결정 | 다시 추가하지 않음 |

**배포 원칙:** 사용자가 아이·어른 동화의 그림·본문과 한국어·영어·스페인어를 최종 검토한 뒤 GitHub 반영을 요청했다. 이는 이전의 ‘어른 작품 공개 보류’에 대한 최신 변경이다. 다만 검수하지 않은 제작 중 결과를 곧바로 완성본으로 공개하지 않는다.

## 3. 정보 구조와 메뉴

### 3.1 기본 구조

```text
마음동화책방 입구
├─ 같은 하루, 다른 마음
│  ├─ 아이의 마음이 담긴 동화
│  │  └─ 여섯 작품 → 동화 읽기 / 다른 마음으로 읽기
│  └─ 어른의 마음이 담긴 동화
│     └─ 세 작품 → 동화 읽기 / 다른 마음으로 읽기
├─ 만약 이랬다면 어땠을까?
│  └─ 청개구리의 무거운 마음
│     ├─ 동화 읽기
│     └─ 마음 건네보기 활동
├─ 마음의 소리
├─ 마음 열쇠 알아보기
├─ 마음으로 만나는 세상 — 준비 중
└─ 처음 오셨나요? 이용안내

공통 상단: 책 목록 / 책방 입구 / 언어 선택
```

위 구조는 최종 제공 범위를 나타낸다. 어른 세 작품은 검수 후 공개 메뉴에 연결했고, 어른 책장의 ‘준비 중’ 표시는 제거했다. 마음으로 만나는 세상의 준비 중 상태는 유지한다.

| ID | 요구사항 | 완료 판단 기준 |
|---|---|---|
| NAV-01 | 아이·어른 책장 구분을 유지한다. | 두 책장을 같은 메뉴 체계에서 찾을 수 있다. |
| NAV-02 | 아이·어른 읽기 메뉴 이름과 순서를 통일한다. | 두 종류 모두 ‘동화 읽기’, ‘다른 마음으로 읽기’를 같은 위치에서 제공한다. |
| NAV-03 | 처음 읽기는 기본 주인공의 첫 장부터 시작한다. | 책을 열자마자 인물 선택을 강요하지 않는다. |
| NAV-04 | 다른 마음으로 읽기에서는 인물을 선택한다. | 선택한 인물의 첫 장부터 시작한다. 아이 작품은 다른 두 인물, 어른 작품은 다른 한 인물을 제공한다. |

| NAV-07 | 취소된 메뉴를 노출하지 않는다. | 마음꾸러미·그림일기·인생게임·마음으로 펼치는 이야기 메뉴가 나타나지 않는다. |

## 4. 주요 사용자 흐름

### 4.1 처음 방문

1. 정지 삽화와 간결한 대문 메뉴를 본다.
2. 처음 이용 안내에서 ‘책 고르기 → 읽고 마음열쇠 살펴보기 → 다른 마음으로 다시 읽기’를 이해한다.
3. 더 긴 설명은 필요할 때 펼친다.
4. 같은 하루, 다른 마음에서 책장을 선택한다.

### 4.2 동화 읽기

1. 책을 고른다.
2. 기본 주인공의 관점으로 첫 장을 읽는다.
3. 그림의 마음열쇠를 눌러 표정·행동·주변 단서를 살펴본다.
4. 다음 장 버튼이나 좌우 넘김으로 이동한다.
5. 마지막 장에서 잠시 돌아본다.
6. 다른 마음으로 읽기를 선택하거나 책장으로 돌아간다.

### 4.3 다른 마음으로 읽기

1. 다른 마음으로 읽기를 선택한다.
2. 인물 카드에서 읽고 싶은 사람을 고른다.
3. 그 사람의 첫 장부터 읽는다.
4. 같은 사건을 그 사람의 눈높이·자리에서 새로 그린 그림과 그 사람의 본문으로 만난다.
5. 처음 읽었던 마음과 달라진 부분을 스스로 발견한다.

## 6. 아이의 마음이 담긴 동화

### 6.1 작품 목록

| 식별자 | 작품명 | 장소 |
|---|---|---|
| errand | 작은 손에 담긴 따뜻한 빵 | 빵집 |
| cups | 생일날, 두 개의 잔 | 생일파티 |
| plate | 마지막 한 조각은 누구에게? | 식당 |
| door | 문 뒤에 숨겨 둔 별 | 집 |
| ball | 노란 공이 기다려 준 날 | 놀이터 |
| stars | 삐뚤빼뚤, 우리의 별 | 학교 |

### 6.2 작품 구조

- 작품마다 여섯 장면을 제공한다.
- 기본 화자 한 명과 다른 인물 두 명, 총 세 관점이 있다.
- 시간·사건·장소는 이어지지만, 각 인물이 보거나 알았던 것은 다르게 쓴다.
- 어린이의 말은 짧고 구체적이며 그림일기처럼 자연스럽게 쓴다.
- 어른 인물이 등장하더라도 어린이 책장 자체를 어른 책장으로 바꾸지 않는다.
- 아이가 이해하기 어려운 추상적 교훈·전문용어·정답 설명을 앞세우지 않는다.

### 6.3 그림과 본문 대조

- 손에 든 물건, 눈의 방향, 입 모양, 표정, 인물의 서 있는 자리와 본문이 일치해야 한다.
- 다른 관점에서 문·잔·공·책·접시·상대 인물의 위치가 모순되지 않아야 한다.
- 그림에 빨간 하트가 있으면 ‘빨간 별’이라고 설명하지 않는다.
- 마음열쇠 확대 그림도 같은 장면의 실제 부위를 사용한다.
- 표정만 보고 속마음을 확정하는 문장보다, 보이는 모습과 가능한 해석을 구분한다.

## 7. 어른의 마음이 담긴 동화

### 7.1 공통 기획

- 어린이 작품과 다른 장소에서 벌어지는 평범한 일상 이야기로 만든다.
- 사소하지만 섬세한 감정과 말하지 못한 마음을 다룬다.
- 폭력·악역·극단적 비극에 기대지 않는다.
- 등장인물 모두 이해할 수 있는 사정이 있도록 쓴다.
- 해설로 교훈을 결론짓기보다 대화·물건·행동이 달라지는 것으로 마무리한다.
- 여섯 장면, 기본 주인공과 다른 한 인물의 두 관점을 제공한다.

### 7.2 접어 둔 소매 한 뼘

| 항목 | 확정 내용 |
|---|---|
| 식별자 | sleeve |
| 장소 | 동네 수선집 |
| 기본 주인공 | 미라 |
| 다른 관점 | 수선사 혜진 |
| 중심 사건 | 오래된 재킷의 소매를 줄이려는데 수선사가 말을 멈춘다. |
| 미라의 해석 | 옷이 낡아 고치기 어려운지, 자신이 힘든 일을 맡긴 건지 걱정한다. |
| 혜진의 사정 | 소매 안쪽의 오래된 손바느질 자국을 남길 방법을 살핀다. |
| 전환 | 미라 어머니의 바느질이라는 사실을 듣고 소중한 부분을 보존한다. |
| 마무리 | 미라는 소중한 부분을 더 말해보기로 하고, 혜진은 남기고 싶은 부분을 먼저 물어보기로 한다. |

원고 표현 기준:

- ‘바느질도 없어질’보다 **‘손바느질한 자국도 함께 없어질’**로 명확히 쓴다.
- ‘낡았다는 말’은 **‘재킷이 낡았다는 손님의 말’**처럼 대상을 밝힌다.
- 미라의 대사: **‘고치기 어려운 옷을 맡겨서 제가 힘들게 해드렸나 싶었어요.’**
- 미라의 깨달음: **‘저도 모르게 이 자국이 지워지지 않기를 바랐나 봐요.’**
- 혜진의 생각: **‘길이를 맞추는 것 말고도 물어볼 것이 있구나.’**

## 9. 마음열쇠

### 9.1 의미와 설명 방식

- 전체 명칭은 **마음 열쇠**로 통일한다.
- 도움말에서는 표정·행동·말의 세 종류를 설명한다.
- **표정:** 눈·입·눈썹에 나타난 모습.
- **행동:** 손짓·몸짓·무엇을 했는지. 냄새를 맡거나 맛보는 모습도 행동에 포함한다.
- **말:** 한 말과 목소리·말투.
- 열쇠 종류를 맞히는 활동이 아니다.
- 관찰 사실과 해석을 구분하고 ‘그럴 수도 있다’는 여지를 남긴다.
- 본문과 같은 해설을 반복하거나 질문을 과도하게 쌓지 않는다. 짧지만 성의 있게 관찰할 단서를 준다.

## 11. 마지막 장과 이용안내

### 11.1 마지막 장

- ‘처음 생각했던 마음과 조금 달라졌나요?’처럼 조용히 돌아볼 여지를 준다.
- ‘답을 적지 않아도 괜찮아요. 잠시 머물렀다가 가세요.’라는 방향을 유지한다.
- 다른 마음으로 읽기와 책장으로 돌아가기 기능을 제공한다.
- 정답·성취 점수·감정 평가·강제 글쓰기·숙제를 요구하지 않는다.

### 11.2 이용안내

- 첫 안내는 짧은 세 단계로 이해할 수 있게 한다.
- 자세한 안내는 접었다 펼칠 수 있게 한다.
- 처음 방문 후에도 이용자가 다시 열어볼 수 있게 한다.
- ‘함께 읽는 어른께’라는 별도 하단 링크는 읽기 화면에서 제거한 방향을 유지한다.
- 함께 나눌 질문은 이용안내의 **함께 이야기 나누기**로 모은다.
- 개인 경험을 반드시 공개하지 않아도 되고, 듣기만 해도 참여임을 알린다.

## 12. 세 언어 제공

**한국어·영어·스페인어는 같은 서비스 구조를 사용한다.** 언어마다 별개의 메뉴 구조나 다른 활동 순서를 만들지 않는다.

## 13. 다른 공개 코너

### 13.1 만약 이랬다면 어땠을까?
