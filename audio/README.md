# 마음의 소리

사용자가 제공한 일상 소리 다섯 개를 짧게 다듬은 체험용 파일입니다.

- everyday-water.mp3: 물을 따르는 소리
- everyday-cooking.mp3: 음식이 지글거리는 소리
- everyday-grain.mp3: 곡식이나 씨앗을 붓는 소리
- everyday-sweeping.mp3: 빗자루로 쓸어내는 소리
- everyday-bread.mp3: 빵을 자르는 소리

화면에서는 실제 이름을 먼저 보여주지 않고 소리 1부터 5로 표시합니다. 정답을 찾는 대신 기억과 풍경을 상상합니다.

인물별 지정 음성과 자동 낭독은 제거했습니다.
