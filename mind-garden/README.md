# 마음정원

마음동화책방 앞마당에서 씨앗을 심고 짧은 이야기를 만나는 게임이다. 화분, 하트, 진행 기록은 이용 중인 브라우저에 저장된다.

일반 페이지는 `index.html`이다. 그림, 글꼴, 소리를 넣은 단일 파일이 필요하면 이 폴더에서 `node build.cjs`를 실행한다.

- 발걸음 [Footsteps on tile.wav · theshuggie · CC0](https://freesound.org/people/theshuggie/sounds/371015/)
- 손수레 [Person Pushing Cart down hallway.wav · WavJunction.com · CC0](https://freesound.org/people/WavJunction.com/sounds/456768/)
- 한국어 엘리베이터 안내는 [Supertonic 3](https://k2-fsa.github.io/sherpa/onnx/tts/all/Korean/supertonic-3-ko.html)로 제작했다. 영어와 스페인어 안내는 한국어 문구를 번역한 뒤 각각 제작한다.
- Hi Melody와 Noto Sans KR의 글꼴 라이선스는 `assets`에 포함했다.
