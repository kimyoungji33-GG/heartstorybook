# 마음동화책방

마음을 읽는 작은 도서관입니다. 어린이용 여섯 권과 어른용 세 권을 한국어·영어·스페인어로 읽을 수 있습니다.

## 이용 방법

1. 어린이용 또는 어른용 책장을 골라 책 표지를 누릅니다.
2. **동화 읽기**에서는 한 사람의 이야기를 큰 그림과 함께 읽습니다.
3. **다른 마음으로 읽기**에서는 같은 순간을 다른 두 인물의 자리에서 다시 봅니다.
4. 그림 속 열쇠에 커서를 올리거나 누르면 표정·말·행동을 살펴볼 수 있습니다. 키보드 Tab과 Enter도 사용할 수 있습니다.
5. 원래 줄무늬 메뉴에는 책 목록이 모두 있습니다. ‘동화책을 읽기 전에’ 묶음에서 **마음의 소리**와 **마음 열쇠 알아보기**를 선택할 수 있습니다.
6. ‘만약 이랬다면 어땠을까?’ 책장에서는 전래동화의 새로운 결말을 만납니다. 책 아래 원작 이름을 표시합니다.

정답을 맞히는 시험이 아닙니다. 눈으로 본 모습과 내 짐작을 나누어 보고, 아직 모르는 마음을 남겨두며 서로의 말을 듣는 활동입니다. 읽기 단계 구분은 사용하지 않습니다. 여러 관점을 통합하는 별도 활동은 아직 넣지 않았습니다.

귀 열쇠는 이야기 속 말을 읽는 기능입니다. 녹음 음성이 나오지는 않습니다. ‘마음의 소리’는 음원 파일이 없으면 브라우저가 만든 짧은 도레미 소리를 사용합니다.

언어를 바꿔도 인물, 그림, 이름의 정체성과 나이는 유지됩니다. 읽는 중에 언어를 바꾸면 페이지와 선택한 관점도 유지됩니다. 언어 선택만 브라우저에 저장하며, 활동 내용을 서버로 보내지 않습니다.

## 미리보기

index.html을 브라우저에서 열면 됩니다. 서버를 쓰려면 이 폴더에서 python -m http.server 4175 --bind 127.0.0.1을 실행한 뒤 http://127.0.0.1:4175/를 여세요.

모든 인물과 이야기는 허구입니다. 코드와 그림 제작에는 OpenAI 도구를 사용했습니다. 외부 글꼴을 불러올 수 없으면 기기의 대체 글꼴을 사용합니다.
