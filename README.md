# 마음동화책방 · 한국어 그림책 체험

어린이용 여섯 권과 어른용 세 권을 큰 그림과 이야기로 읽는 웹사이트입니다. GitHub Pages에서 체험할 수 있습니다.

## 이용 방법

1. `index.html`에서 이용안내를 읽고 어린이용 또는 어른용 책장을 선택합니다.
2. 책 표지를 고르고 **동화 읽기**나 **마음 활동**을 선택합니다.
3. 동화 읽기는 한 명의 이야기입니다. 큰 그림 아래 글을 읽고, 그림의 열쇠에 커서를 올리거나 눌러 표정·이야기 속 말·행동을 살펴봅니다. 키보드 Tab과 Enter로도 사용할 수 있습니다.
4. 마음 활동에서는 다른 두 인물의 자리에서 같은 순간을 봅니다. 인물별로 보는 방향과 생각이 달라지고, 각 그림의 마음 열쇠도 달라집니다.
5. 메뉴의 **만약 이랬다면 어땠을까?**에서 청개구리 책을 펼칠 수 있습니다. 표지 아래에 원작 이름을 표시합니다.
6. **마음의 소리**는 같은 소리에서 떠오르는 서로 다른 풍경을 고르는 활동입니다. 소리 파일이 없으면 브라우저가 만든 짧은 음을 사용합니다.

마음을 맞히는 시험이 아닙니다. 눈에 보이는 모습에서 조심스럽게 짐작하고, 아직 모르는 마음은 남겨 두며 서로의 말을 들어 봅니다. 귀 열쇠는 이야기의 말을 살펴보며 녹음 음성은 아닙니다.

이용안내는 책방 아래 버튼으로 다시 열 수 있습니다. 마음을 걷는 이야기는 제거했습니다.

이번 새 독자 화면은 한국어 체험판입니다. 기존 언어 선택은 유지하며, 새 등장인물 정보에는 한국어·영어·스페인어 이름을 함께 준비했습니다. 언어 때문에 그림 속 인물을 바꾸지 않습니다.

인물들은 허구이며, 특정 외모로 국적이나 마음을 판단하지 않습니다.

## 미리보기

index.html을 브라우저에서 열면 됩니다. 로컬 서버를 쓰려면 이 폴더에서 `python -m http.server 4175 --bind 127.0.0.1`을 실행한 뒤 `http://127.0.0.1:4175/`를 여세요.
