# 마음동화책방

**마음을 읽는 작은 도서관**

같은 상황을 여러 등장인물의 눈으로 읽으며 서로 다른 마음을 이해하는 웹앱입니다. 어린이용 이야기 7권과 어른용 이야기 3권이 있으며 한국어·영어·스페인어를 선택할 수 있습니다. 모든 인물과 이야기는 허구입니다.

## 사용하기

1. 언어와 책방을 선택하고 책 표지를 누릅니다.
2. **동화 읽기** 또는 **마음 활동**을 고릅니다.
3. 등장인물을 골라 그 사람의 이야기를 읽습니다.
4. 마음 활동에서는 작은 단서를 살펴봅니다. 마지막에는 다른 등장인물의 얼굴을 눌러 같은 상황을 다른 관점에서 읽을 수 있습니다.

## 내 컴퓨터에서 보기

이 폴더의 `index.html`을 더블 클릭해 Chrome 또는 Edge로 열면 됩니다. 별도의 설치는 필요하지 않습니다.

## GitHub Pages에 올리기

이 폴더 **안의 파일들**을 GitHub 저장소의 맨 위에 올립니다. `index.html`을 다른 폴더 안에 넣지 않습니다. 그림과 코드 파일도 함께 올려야 합니다. ZIP 파일 자체를 올리는 방식은 아닙니다.

HTML·CSS·JavaScript로만 구성되어 별도의 서버나 빌드 과정이 필요하지 않습니다. `.nojekyll`은 GitHub Pages가 파일을 그대로 제공하도록 하는 빈 파일입니다.

## 파일 안내

- `index.html`: 시작 화면
- `library.css`: 글꼴, 색상, 화면 배치
- `library.js`: 책 선택, 언어 변경, 동화 읽기와 활동
- `stories.js`: 세 언어의 이야기와 단서
- PNG 파일 6개: 도서관, 동화 장면, 등장인물 그림
- `.nojekyll`: GitHub Pages용 빈 파일
- `.gitignore`: 올리지 않을 임시 파일 등의 목록

## 저장과 글꼴

선택한 언어만 이 브라우저의 `localStorage`에 저장합니다. 활동 답변을 서버로 보내거나 저장하지 않습니다.

사이트 안의 코드와 그림은 상대 경로로 불러옵니다. 글꼴만 외부 서비스인 Google Fonts에서 가져오며, 인터넷이 없으면 기기에 있는 대체 글꼴로 표시됩니다.

기획과 화면 방향은 사용자가 정했으며 코드·번역 초안·그림 제작에는 OpenAI 도구를 사용했습니다.

## 추가된 이야기

어린이용 책방은 **같은 하루, 다른 마음**(서로의 마음을 따라 읽는 이야기)과 **만약 이랬다면 어땠을까?**(다르게 펼쳐보는 전래동화) 두 카테고리로 나뉩니다.

청개구리 책은 동화 읽기 6장과 마음 활동을 제공합니다. 감정을 여러 개 고르고, 긍정적인 표현으로 대화를 이어가며 엄마의 마음을 알아봅니다. 점수나 정답 판정은 없습니다. 그림 7장은 제공받은 수업 PPT의 원본을 그대로 사용했습니다. 게임의 대화와 분기 결말은 새롭게 구성한 내용입니다.

- frog.js: 청개구리 읽기·활동 및 카테고리 표시
- frog-cover.png, frog-1.png부터 frog-6.png: 원본 PPT의 표지·장면 그림
