# 내 마음이 걷는 이야기

피드백을 받기 위한 한국어 게임 체험판입니다. 그림 속에서 행동과 대화를 선택하면 이어지는 장면과 마지막 마음 산책 일기가 달라집니다. 현재 움직임은 정지 그림에 카메라 이동을 더한 애니메이션이며 실제 거리 동영상은 아닙니다.

이야기는 입력과 준비된 분기로 만들어집니다. 상대의 대화와 결과는 상상이며 실제 상대의 마음이라고 단정하지 않습니다. 정답이나 점수는 없습니다.

입력은 메모리에만 남습니다. 서버에 보내거나 브라우저 저장소에 저장하지 않습니다. 새로고침하면 없어지고, 저장 버튼을 선택할 때만 사용자의 컴퓨터에 텍스트 파일을 저장합니다. 실명·학교·전화번호·주소 등 개인정보는 입력하지 마세요. 화면 공유 전 가림 기능을 이용하고 내용을 확인해 주세요.

우화 원문: 미국 의회도서관 [사자와 생쥐](https://www.read.gov/aesop/007.html), [북풍과 태양](https://read.gov/aesop/143.html). 그림은 이 프로젝트를 위해 생성했습니다.
